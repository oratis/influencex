# KOL 外联邮件能力升级方案

## 一、需求结论

基于当前平台结构，本需求**不建议作为 Conductor 的独立主模块**来做，而应以 **Contacts 为主入口**进行扩展。

Contacts 目前已承担 KOL 外联与合作跟踪流程，现有流程本身就包含 Write / Review / Send / Monitor，与邮件发送、状态追踪、沟通记录的需求高度一致。

落位方式：

| 模块 | 一期职责 |
| --- | --- |
| **Contacts** | 主页面，批量发送、单个发送、邮件状态、沟通记录 |
| **Connections** | 邮箱授权、发件账号配置 |
| **Pipeline** | 后台发送任务、追踪任务、失败重试任务 |
| **Conductor** | 二期自动化编排入口，不作为一期主操作界面 |

---

## 二、需求背景

当前平台已支持 KOL 外联流程中的邮件草稿生成，但邮件能力还不完整。实际使用中需要：

- 给多个博主**批量发送**邮件
- 给单个博主**单独定制**发送邮件
- 发送后**查看邮件状态**
- 查看**已读、回复、送达**等数据
- 查看我方与博主之间的**完整沟通记录**

因此需要把平台现有的外联流程升级为「可发送、可追踪、可沉淀记录」的完整闭环。

---

## 三、页面与模块落位建议

### 3.1 Contacts —— 主入口

- 这里本身就是 KOL 外联流程页,用户会在此筛选、审核、跟进博主
- 建议把邮件能力**直接嵌入 Contacts 工作流**,而不是新开一个割裂的「邮件中心」

### 3.2 Connections —— 邮箱配置入口

- 负责邮箱授权、发件账号绑定、发件人信息、签名等设置
- 属于系统连接能力,归于 Connections

### 3.3 Pipeline —— 后台任务页

- 批量发送、发送追踪、失败重试、已读监控等都是异步任务
- 这些任务在 Pipeline 中展示状态和进度

### 3.4 Conductor —— 二期能力

- 后续支持一句话触发自动化流程,例如「给当前 campaign 下已审批 KOL 生成并发送首轮外联邮件」
- 一期不做成主入口,避免偏离 Conductor 定位

---

## 四、一期核心功能需求

### 4.1 批量发送邮件 (Contacts)

**位置**:Contacts 页顶部和列表操作区

**功能要求**:
- 支持勾选多个 KOL 后批量发送
- 支持选择邮件模板
- 支持自动替换变量:博主姓名、平台名、campaign 名称等
- 发送前预览
- 立即发送
- 发送失败后重试
- 批量发送后生成任务记录,状态同步到 Pipeline

### 4.2 单个博主定制发送 (Contacts)

**位置**:Contacts 每个 KOL 行操作

**功能要求**:
- 每个 KOL 行增加 `Send Email` 或 `Open Thread` 按钮
- 点击后打开右侧抽屉或弹窗
- 支持单独编辑主题、正文、签名、附件
- 支持基于模板快速填充,再人工修改
- 支持发送后继续在同一会话里跟进

### 4.3 邮件状态追踪 (Contacts)

每个 KOL 需显示邮件状态:

| 状态 | 含义 |
| --- | --- |
| `draft` | 草稿 |
| `pending` | 待发送 |
| `sent` | 已发送 |
| `delivered` | 已送达 |
| `opened` | 已读 |
| `replied` | 已回复 |
| `failed` | 发送失败 |
| `bounced` | 退信 |

**展示字段**:
- 最近发送时间
- 最近送达时间
- 首次已读时间
- 最近回复时间
- 当前最新状态

### 4.4 沟通记录管理 (Contacts)

**位置**:Contacts 的会话抽屉

**功能要求**:
- 按 KOL 展示完整邮件往来记录
- 展示我方发送内容 + 对方回复内容
- 每次沟通的时间
- **按线程 (thread) 展示**,方便连续跟进

### 4.5 邮件模板管理

**位置**:Contacts 内部入口,或后续独立成模板页

**功能要求**:
- 新建 / 编辑 / 保存模板
- 设置变量字段
- 发送前预览最终内容

### 4.6 邮箱授权与发件配置 (Connections)

**功能要求**:
- 绑定邮箱账号
- 设置发件人名称
- 设置邮箱签名
- 多邮箱切换
- 显示授权状态

### 4.7 后台任务与监控 (Pipeline)

**功能要求**:
- 显示批量发送任务进度
- 显示邮件状态监控任务
- 显示失败重试任务
- 显示异常原因

---

## 五、建议的页面改造方式

### 5.1 Contacts 页面新增

- 顶部增加 **Bulk Send Email** 按钮
- 列表中每个 KOL 增加 **Send Email** 按钮
- 列表增加**邮件状态字段**
- 点击 KOL 或按钮后打开**邮件沟通抽屉**,抽屉包含:
  - 当前联系人信息
  - 历史沟通记录
  - 单独发送编辑区
  - 最新状态与时间线

### 5.2 Connections 页面新增

- 邮箱连接卡片
- 邮箱授权与发件身份设置
- 多账号管理

### 5.3 Pipeline 页面新增

- 邮件发送任务分类
- 邮件追踪任务分类
- 失败重试记录

---

## 六、一期与二期范围

### 一期 (本次实施)

1. Contacts 内批量发送
2. Contacts 内单个发送
3. 邮件状态展示
4. 沟通记录展示
5. Connections 邮箱授权
6. Pipeline 任务进度展示

### 二期

1. Conductor 一句话触发外联流程
2. 自动化跟进策略
3. 定时发送
4. A/B 模板测试
5. 邮件效果统计报表升级

---

## 七、给 AI 的开发指令 (可直接复用)

> 请基于现有平台结构,为 **Contacts 模块**增加完整的 KOL 外联邮件能力,**不要**在 Conductor 中单独新建一个邮件主模块。
>
> 目标是让 Contacts 成为邮件外联主工作台,支持:
> - 批量发送邮件
> - 单个 KOL 定制发送邮件
> - 邮件模板选择与变量替换
> - 邮件发送状态追踪
> - 已读、回复、送达状态展示
> - 按 KOL 查看完整沟通记录
>
> 同时:
> - 在 **Connections** 中增加邮箱授权与发件账号配置
> - 在 **Pipeline** 中展示邮件发送任务、追踪任务、失败重试任务
>
> **Conductor 暂不作为一期主入口**,仅保留为未来自动化编排能力。
